# github-workflow-practice

A small learning repository for practicing GitHub issues, branches, and pull requests. It provides a place to learn the contribution workflow using documentation changes. This repository belongs to Oleg Soroko and has no application, build system, or runtime dependencies.

## Features

- A starter repository using `main` as its default branch.
- A documented place to practice GitHub collaboration tools.
- No packages or services to install.

## Getting started

1. Open this repository on GitHub and read this README.
2. Use **Issues** to describe a small task and its completion criteria.
3. Make a focused change in a branch, open a pull request into `main`, and inspect the difference before merging.

## Controls

- **Issues → New issue** records a task.
- **Close issue** marks a finished task as completed.
- **Pull requests → New pull request** proposes a branch for merging.
- **Files changed** shows the proposed changes.
- **Merge pull request** integrates a ready change into `main`.

## Achievement visibility

GitHub awards profile achievements automatically. This repository does not guarantee a badge or a processing time. To show earned achievements, enable **Show Achievements on my profile** in [profile settings](https://github.com/settings/profile).
