# Practice the issue workflow

An issue records a task, its context, and the conditions that make it complete. Use a real documentation or maintenance task in this repository when practicing.

## Open a task

1. Open **Issues** and select **New issue**.
2. Give the issue an action-oriented title, such as `Clarify a step in the getting started guide`.
3. Explain what is missing and how a reader will benefit from the change.
4. Add specific completion criteria using the checklist below.

```markdown
## Task
Describe the change and who it helps.

## Completion criteria
- [ ] The requested change is present.
- [ ] Instructions and file links have been checked.
- [ ] The result is recorded in this issue or a linked pull request.
```

## Complete a task

1. Perform the work and check every completion criterion.
2. Record what you verified and update the checkboxes.
3. Use **Close issue** when the task is complete.

If a pull request implements the task, include `Closes #NUMBER` in the PR description. GitHub closes the linked issue when the PR is merged into the default branch.
